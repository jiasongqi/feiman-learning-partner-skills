# 费曼学习法 AI 追问伙伴

> 一个让你真正搞懂知识的 WorkBuddy Skill —— AI 扮演零基础新人，持续追问直到你讲清楚。

---

## 是什么

这个 Skill 把费曼学习法搬进了 AI 对话里。

**费曼学习法的核心逻辑很简单：** 如果你真的懂一件事，你能把它讲给一个完全不懂的人听。讲不清楚，就说明你没真懂。

所以这个 Skill 让 AI 扮演那个"完全不懂的人"——你来讲，AI 来追问。追到你真讲清楚了为止。

---

## 适合什么场景

- 听完一期播客/看完一本书，想内化核心知识
- 学了一个新概念，想检验自己是否真的理解
- 准备向别人解释一个技术/商业概念，提前演练
- 任何你觉得"我懂了但说不清楚"的知识点

## 学习流程（三阶段）

```
第一阶段：你讲 → AI 持续追问
         ↓
第二阶段：AI 出 5~10 道考题 → 你回答
         ↓
第三阶段：AI 输出结构化总结
```

### 第一阶段：持续追问

AI 会以新手视角不断提问：

- **基础问题**：这是什么意思？为什么会这样？举个例子？
- **发现模糊**：这句话太抽象了 / 这里逻辑跳跃了 / 这个词没解释
- **挖底层逻辑**：本质是什么？解决了什么问题？和其他方案区别在哪？
- **验证理解**：让我复述一遍 / 你举个反例 / 用生活场景解释

### 第二阶段：知识验收

你觉得讲完了？AI 会出题考你——基础理解题、场景应用题、对比题、为什么题、举例题，全部答出来才算通过。

### 第三阶段：总结输出

验收通过后，AI 输出六个模块的结构化总结：

| 模块 | 内容 |
|------|------|
| 20% 核心知识 | 最重要的 10 条，每条一句话 |
| 一句话讲明白 | 本质上就是：______ |
| 生活化比喻 | 这就像：______ |
| 学完能解决什么问题 | 实际应用价值 |
| 你讲得不清楚的地方 | AI 帮你找漏洞 |
| 你遗漏的知识点 | 必须补充 + 进阶 + 踩坑 |

## 为什么有效

传统学习方式是"输入"——看书、听课、刷视频。  
费曼学习法是"输出倒逼输入"——你必须用自己的语言讲出来，才能发现自己哪里没真懂。

AI 追问的优势在于：

1. **不会因为礼貌就放过你** —— 人类听众可能不好意思追问，AI 不会
2. **问题有结构** —— 按照新手视角 → 底层逻辑 → 验证理解的顺序推进
3. **最后有验收** —— 不只是聊天，而是真正考核你的掌握程度
